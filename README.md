# Les défis de Shams

Application d'entraînement scolaire pour un enfant de CM2, sous forme d'un fichier HTML unique et autonome.

## Utiliser l'application

Deux façons de l'ouvrir :

- **En ligne** (une fois publiée avec GitHub Pages) : ouvre simplement l'URL du site.
- **Hors ligne** : double-clique sur `index.html` pour l'ouvrir dans n'importe quel navigateur récent. Aucune connexion internet, aucune installation, aucune donnée envoyée en ligne.

## Contenu

14 modules (français, mathématiques, histoire), avec rappel de règle imagé, exercices interactifs à feedback immédiat, gamification (points, étoiles, badges) et suivi de progression.

## Technique

- Un seul fichier `index.html` : HTML + CSS + JavaScript vanilla, aucune dépendance externe.
- Progression sauvegardée dans le `localStorage` du navigateur (rien n'est envoyé à un serveur).
- Bouton "Réinitialiser ma progression" dans les réglages de l'application.
